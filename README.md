# Ola Ride Booking Data Analysis

## About the Project

This project is a data analysis project based on Ola ride booking data. 
The main goal of the project was to understand booking patterns, vehicle 
performance, revenue, cancellations, and customer and driver ratings.

I worked with the data using Excel and SQL for data preparation and analysis, 
and used Power BI to create an interactive dashboard.

The project helped me practice how raw booking data can be converted into 
useful information through data cleaning, SQL analysis, and visualization.

---

## Tools Used

- Microsoft Excel
- MySQL Workbench
- Power BI
- DAX
- Data Visualization

---

## Project Workflow

The project was completed in the following steps:

1. Collected and reviewed the Ola booking dataset
2. Prepared and checked the data using Excel
3. Used SQL to analyze the booking data and answer business questions
4. Created calculated measures for important KPIs
5. Built an interactive Power BI dashboard
6. Used charts, tables, and filters to understand the data
7. Reviewed the results and identified useful patterns

---

## Power BI Dashboard

The Power BI report is divided into five main sections:

### 1. Overall

This page gives a general view of the Ola bookings.

It includes:

- Total bookings
- Booking status breakdown
- Ride volume over time
- Date filtering
- Overall booking performance

The dashboard shows more than 100K bookings in the selected overall view and 
provides a breakdown between successful bookings, customer cancellations, 
driver cancellations, and driver-not-found bookings.

---

### 2. Vehicle Type

This page compares different vehicle categories.

Vehicle types included in the dashboard are:

- Prime Sedan
- Prime SUV
- Prime Plus
- Mini
- Auto
- Bike
- E-Bike

The analysis includes:

- Total booking value
- Successful booking value
- Average distance travelled
- Total distance travelled

This makes it easier to compare how different vehicle types perform.

---

### 3. Revenue

The revenue page focuses on payment and booking-value analysis.

It includes:

- Revenue by payment method
- Payment method comparison
- Top customers
- Ride-distance trends over time
- Date filtering

Payment methods shown in the dashboard include:

- Cash
- UPI
- Credit Card
- Debit Card

---

### 4. Cancellation

The cancellation page looks at cancelled rides and their reasons.

It includes:

- Total bookings
- Successful bookings
- Cancelled bookings
- Cancellation analysis
- Customer cancellation reasons
- Driver cancellation reasons

Some of the cancellation reasons analyzed include:

- Driver is not moving towards the customer
- Driver asked to cancel
- Change of plans
- AC is not working
- Wrong address
- Personal & car-related issues
- Customer-related issues
- More than permitted passengers

This section helped me understand where cancellations were happening and 
what reasons were associated with them.

---

### 5. Ratings

The ratings page compares driver and customer ratings across different 
vehicle types.

The dashboard includes ratings for:

- Prime Sedan
- Prime SUV
- Prime Plus
- Mini
- Auto
- Bike
- E-Bike

This provides a simple comparison between driver ratings and customer 
ratings for different vehicle categories.

---

## SQL Analysis

SQL was used to explore the booking data and answer business-related 
questions.

Some of the analysis included:

- Finding successful bookings
- Calculating average ride distance by vehicle type
- Identifying customers with cancelled rides
- Finding the top customers based on rides
- Analyzing driver cancellation reasons
- Checking payment methods
- Analyzing incomplete rides
- Comparing vehicle ratings
